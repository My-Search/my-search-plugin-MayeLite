# MayeLite 快速启动

为「我的搜索」开发的文件/文件夹快速启动插件，交互参考 [Maye Lite](https://github.com/25H/MayeLite)。

把常用文件或文件夹**拖进插件界面即可固定**，之后随时一键打开。

![图标视图（浅色）](test/_shot-light-icon.png)
![列表视图（深色）](test/_shot-dark-list.png)

## 功能

| 功能 | 说明 |
| --- | --- |
| 拖拽固定 | 把文件/文件夹拖到插件界面即固定；同一路径重复拖入自动去重 |
| 分类 | 新建/重命名/删除分类，条目可在分类间移动（删除分类不删条目，归入「未分类」） |
| 排序 | 手动（置顶/上移/下移）、添加时间、名称、类型；可升降序 |
| 视图 | 图标视图 / 列表视图，偏好持久化 |
| 过滤 | 顶部搜索框过滤（名称 + 路径，空格分词 AND），也支持「快速启动 : 关键词」子搜索 |
| 打开 | 单击条目打开；右键菜单可重命名、复制路径、在资源管理器中定位、移动分类、移除 |
| 图标 | 资源管理器同款系统图标；取不到时退回内联 SVG 字形（不留空白） |

快捷键：`Enter` 打开聚焦项，`Esc` 关闭菜单/浮层或清空过滤。

**全局快捷键**：默认 `Ctrl+Alt+B` 呼出（在「我的搜索」里随时按下即可打开快速启动视图，
并自动聚焦过滤框，直接输入关键词过滤固定项）。可在「设置 → 快捷键」里改键或解绑——
作用类型显示为「快速启动（呼出）」。

## 安装

**从插件市场**：在「我的搜索」里搜「快速启动」或「MayeLite」，直接安装。

**手动**：从 [Releases](https://github.com/My-Search/my-search-plugin-MayeLite/releases) 下载
`.mspp`，拖进搜索框或双击安装。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.inlay` | 在搜索详情区渲染插件界面（必需） |
| `store` | 保存固定项与偏好（必需） |
| `file.read` | 读取**已拖入/粘贴**的路径，用于判断类型与获取系统图标 |
| `ui.notify` | 操作后的轻提示 |
| `clipboard.write`（可选） | 右键「复制路径」；未授予时自动回退到浏览器剪贴板 |

## 设计说明

### 固定项如何跨会话打开

宿主的 `ms.input.*` 全部受 `file.read` 权限与**「路径必须落在已登记的附加集合内」**
双重校验，而那个集合是 Rust 进程内的静态表：只由用户**当场**粘贴/拖入产生，
**应用重启后清空**，且插件无权自行登记。

所以打开走两层降级：

1. `ms.input.open(path)` —— 本次会话拖入过、已被宿主登记的路径（文档化通道）；
2. 宿主注入的 `openExternal(path)` —— 跨会话的固定项，把本地路径交给系统默认程序。

「在资源管理器中定位」同理：已登记路径用 `ms.input.reveal`（能**选中**该条目），
跨会话时降级为打开所在目录。

### 图标为什么要在固定时抓

`ms.input.fileIcons` 也只对已登记路径生效，重启后拿不到。因此本插件在**固定那一刻**
把图标字节（PNG data URL）一并存进 `ms.store`，重启后照样显示真实图标。

存储有预算上限（1.5MB），超出时从**最旧**的条目开始丢弃图标（条目本身保留）。

### 生命周期

清单声明 `closeBehavior: "minimize"`：关闭界面只是把 DOM 停放到宿主停车区，
脚本上下文**保活**（不会重跑）。所以：

- 任何写操作都必须**即时落盘**，不能等卸载时保存；
- 重开时不能指望重新初始化。

同时，保活与热重载会**再次执行**入口脚本，而 `document` 上的监听器不随旧 DOM 消失。
因此每个 document 级回调都先做存活自检（`isAlive()`），否则会「一次拖入固定两遍」。

## 开发

仓库**自带打包器**（`tools/`，与宿主同一份 zip 实现），不需要宿主仓库即可构建。

```bash
# 打包 + 校验（校验走客户端安装时的同一条 preparePackage 链路）
node test/verify-package.mjs

# UI 端到端测试（真实浏览器 + 模拟宿主 IPC；需本机装有 Chrome / Edge）
node test/plugin-ui.test.mjs
# 若宿主仓库在同级目录，会自动用它最新的 scopeCss / 主题变量；
# 也可显式指定：MS_HOST_REPO=/path/to/my-search-desktop node test/plugin-ui.test.mjs

# 生成视觉快照（图标/列表 × 浅色/深色）
node test/_shot.mjs
```

### 测试覆盖

`test/plugin-ui.test.mjs` 用 CDP 驱动真实浏览器，还原宿主的真实渲染条件
（容器层级 `#text_show > .plugin-view`、CSS 经 `scopeCss` 加前缀、主题变量来自宿主），
覆盖 52 项断言，其中包括几条**真实踩过的坑**：

- 拖入固定、去重、持久化（刷新后条目/分类/偏好完整还原）；
- 打开与定位的**降级**（跨会话路径必须走 `openExternal`，否则重启后点不开）；
- 图标在固定时抓取并持久化；
- 启动补抓图标后**必须自动重绘**（曾经漏返回数量，导致图标抓到了界面却不刷新）；
- 插件必须**自带背景色**（宿主不给插件区背景，暗色主题下会露白底）；
- 重挂后老实例不再响应（否则一次拖入固定两遍）；
- 旧宿主降级（没有 `fileIcons` 时纯字形回退，不报错）。

## 发布

按插件市场规范：**tag = 插件 id**（`com.my-search.mayelite`，稳定不变），
资产名 `<插件id>.mspp`。改 `plugin.json` 的 `version` 后推 `main`，
GitHub Actions 会自动打包、校验并覆盖上传到同一个 tag。

```bash
# 手动发版
node test/verify-package.mjs
gh release upload com.my-search.mayelite dist/com.my-search.mayelite.mspp --clobber
```
